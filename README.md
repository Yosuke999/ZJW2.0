# 中亚商机网前台原型

面向吉尔吉斯斯坦与乌兹别克斯坦小生意经营者的高保真商品与参考价格对比前台。项目采用标准 Next.js、React 与 TypeScript 构建，首版部署目标为 Vercel；不包含后台、登录、支付、数据库或真实采价。

## 安装、运行与验证

要求 Node.js 22.13 或更高版本。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

完整质量检查：

```bash
pnpm lint
pnpm build
pnpm test
```

生产构建可用 `pnpm start` 启动。

## 页面路由

- `/kg`：吉尔吉斯语
- `/kg/ru`：俄语
- `/kg/zh`：中文内部预览
- `/uz`：乌兹别克语
- `/uz/ru`：俄语
- `/uz/zh`：中文内部预览

路由可附带匿名来源参数，例如 `/kg?src=train`。切换语言时会保留该参数；参数只进入内存事件占位，不改变国家、语言、价格或联系方式。

## 数据与替换点

- `data/countries.ts`：国家、货币、默认语言和演示联系方式
- `data/products.ts`：20 件商品、四语名称/规格和图片路径
- `public/products/`：20 张白底商品占位图
- `data/prices.ts`：两国演示价格、币种、数量口径、确认日期与状态
- `data/translations.ts`：四种语言的界面文案、品牌名与翻译审核状态
- `lib/analytics.ts`：不联网、不持久化的匿名事件接口占位

未来接入 Supabase 时，应以独立表替换国家配置、商品、国家商品价格、联系方式和翻译数据；组件继续消费现有数据接口，不直接耦合数据库。

## 公开上线前必须处理

当前商品图片均标记为 `imageStatus: 'placeholder'`，仅用于原型演示。公开上线前必须替换为自有或已获授权的真实商品图片。

页面价格均为演示参考价格，联系方式均为不可用的演示配置，不可直接公开使用。中文、吉尔吉斯语、乌兹别克语和俄语版本当前均为 `translationStatus: 'draft'`；正式公开前须由人工完成三种目标语言及中文工作稿校对，并完成真实价格、联系人、法律与隐私合规核验。
